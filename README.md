# BALI, BETWEEN US

2026년 10월 21일부터 11월 4일까지, 우붓·길리 에어·시드멘·울루와뚜를 잇는 14박 15일 트로피컬 여행 플래너입니다.

## 담긴 내용

- 날짜별 여행 동선과 항공편
- 실제 날짜로 조회한 숙소 후보와 예약 링크
- 지역별 관광명소와 맛집
- 패스트보트·입국·종교휴일 주의사항
- 2인 예상 예산과 기기에 저장되는 준비 체크리스트

## 로컬 실행

```bash
npm install
npm run dev
```

GitHub Pages용 정적 사이트는 `npm run build:pages`로 생성됩니다.
